<objective>
Add a fail-fast Automation-permission probe that runs at startup before any MCP transport binds, errors loudly (never hangs) when the OmniFocus Automation grant is missing or revoked, and supersedes the existing non-blocking permission warning. Closes DEPLOY-03.

Purpose: Under launchd there is no Automation consent dialog — a lost grant fails silently. A loud non-zero exit (routed
to the plist StandardErrorPath) is the only way the user learns the grant is gone, and `KeepAlive=Crashed-only`
(Plan 03) keeps that clean exit from restart-looping. Output: `src/utils/automation-probe.ts`, its unit test, and the
wired call in `src/index.ts`. </objective>
