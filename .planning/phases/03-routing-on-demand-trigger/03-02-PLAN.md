    ROUTING DECISION RULES SECTION:
    The exact three-step ladder and confidence rules from 03-PATTERNS.md:
    1. MATCH — Project name clearly identifies this item's home (high confidence). File it there. Do not guess on ambiguous names.
    2. INFER — No obvious project match, but a vault note's omnifocus-project field deterministically names the target. Create the project (if missing) and file there.
