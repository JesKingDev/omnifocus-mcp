    - Module JSDoc header cites D-04, D-05, D-09, D-10 and lists forbidden anti-patterns:
      (1) early return on first match, (2) === compare, (3) timingSafeEqual without hash normalization.

## Trust Boundaries

| Boundary                           | Description                                                                                     |
| ---------------------------------- | ----------------------------------------------------------------------------------------------- |
| env vars → token registry          | Untrusted env values are the token material; the registry treats them as opaque strings to hash |
| candidate token → validateTokenSet | Per-request bearer token from HTTP header; must not leak timing info                            |

## STRIDE Threat Register

| Threat ID  | Category               | Component                                                | Disposition | Mitigation Plan                                                                                                                              |
| ---------- | ---------------------- | -------------------------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| T-04-02-01 | Information Disclosure | validateTokenSet timing                                  | mitigate    | SHA-256 hash normalization collapses all lengths to 32 bytes before timingSafeEqual; accumulate-then-branch loop never short-circuits (D-04) |
| T-04-02-02 | Information Disclosure | timingSafeEqual RangeError as timing oracle              | mitigate    | Both sides hashed to SHA-256 (fixed 32 bytes) before comparison; throw path is eliminated (D-04, Pitfall 1)                                  |
| T-04-02-03 | Spoofing               | resolveHttpIdentity returning wrong principal            | mitigate    | principal is sourced directly from the validated TokenEntry, not from env or a global; no ambiguity about which entry matched                |
| T-04-02-04 | Elevation of Privilege | MCP_AUTH_TOKEN alias granting agent role unintentionally | accept      | D-11 explicitly allows alias; backward-compat is the stated goal; alias only applies when MCP_AGENT_TOKEN is absent                          |
| T-04-02-SC | Tampering              | npm installs                                             | accept      | No new packages; node:crypto is stdlib                                                                                                       |

</threat_model>
