    the read-back result. Collect all returned task objects across chunks into a single flat array.
    Wrap the entire read-back in try/catch: if any chunk's execJson rejects, return
    `createErrorResponseV2('omnifocus_write', VERIFY_READBACK_FAILED, '...', '...', { cause }, originalMetadata)`.

## Trust Boundaries

| Boundary                              | Description                                                            |
| ------------------------------------- | ---------------------------------------------------------------------- |
| agent mutation result → WriteVerifier | Mutation result from OmniJS execution — duck-typed defensively         |
| WriteVerifier → execJson (read-back)  | Second independent osascript spawn — fresh process, no cache           |
| WriteVerifier → field-comparator      | Intent keys are server-generated (from compiledOp), not raw user input |

| ---------- | ---------------------- | ---------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-05-04-01 | Tampering              | skipped-set inflation        | mitigate    | D-11: closed-set check is explicit code paths (dryRun flag + documented no-read-back ops); any new skipped case requires code change, not data; unit test asserts no other path returns 'skipped' |
| T-05-04-02 | Elevation of Privilege | owner skipped vs unverified  | mitigate    | D-12: owner path explicitly sets 'unverified', not 'skipped'; unit test D-12 guards this distinction                                                                                              |
| T-05-04-03 | Information Disclosure | stale read-back              | mitigate    | execJson is injected (not routed through CacheManager); the injected execJson from OmniFocusWriteTool.execJson.bind(this) is the direct script execution path confirmed to bypass cache           |

| T-05-04-05 | Repudiation            | mismatch without audit trail | mitigate    | WRITE_UNVERIFIED_MISMATCH error envelope includes mismatchedFields, intentSnapshot, readBackSnapshot in details — caller has full evidence for retry decision                                     |
