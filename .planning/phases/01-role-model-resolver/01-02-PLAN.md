| T-1-01 | Elevation of Privilege | parseRole — fail-open by mis-implementation | **mitigate (HIGH)** | Structural whitelist: only `env.OMNIFOCUS_MCP_ROLE === 'owner'` returns 'owner'; the exhaustive 14-class parse matrix is the verification gate — without it the fail-safe is trust-based. Anti-patterns explicitly excluded: no toLowerCase, no trim, no truthy-check, no `\|\| 'owner'` fallback |
| T-1-02 | Information Disclosure | identity/authz conflation | mitigate | resolveStdioIdentity and parseRole are separately exported functions with different return types; no single call returns both |
| T-1-04 | Elevation of Privilege | HTTP stub returns wrong role | mitigate | resolveHttpIdentity stub always returns 'fail-safe-default' / AGENT; Phase 4 fills the body under test before any real token→role path is wired |
| T-1-SC | Tampering | npm/pip/cargo installs | accept | No new packages — pure TypeScript with no new dependencies |
